# Quiz

Полноценный мобильный сайт с развлекательными тестами и админ-панелью на `PHP 8 + MySQL 8`, подготовленный для обычного shared hosting на REG.RU.

## Что умеет проект

- Главная страница со всеми опубликованными тестами
- Красивые ЧПУ-URL
- Прохождение теста по шагам
- Обязательный ввод никнейма перед стартом
- Подсчет результата по связям ответов с результатами
- Сохранение прохождений в БД
- Светлая и темная тема с ручным переключателем
- Админ-панель с авторизацией
- CRUD для тестов, результатов, вопросов и ответов
- Загрузка изображений
- Дашборд со статистикой
- Страницы ошибок `403`, `404`, `500`
- `robots.txt`, `sitemap.xml`, `favicon`, `.htaccess`

## Технологии

## Требования

- PHP `8.0` или выше
- MySQL `8.0` или выше
- Apache с включенным `mod_rewrite`
- Доступ к phpMyAdmin или импорту SQL на хостинге

## Установка локально

1. Скопируйте проект в локальную папку.
2. Создайте базу данных MySQL `u3481923_tests` или убедитесь, что она уже создана на хостинге.
3. Отредактируйте файл `config/config.php`.
4. Укажите:
   - `base_url`
   - `db.host`
   - `db.database`
   - `db.username`
   - `db.password`
5. Импортируйте SQL-файлы:
   - сначала `database/schema.sql`
   - затем `database/seed.sql`
6. Убедитесь, что папка `uploads/` доступна для записи.
7. Запустите локальный Apache/PHP и откройте сайт в браузере.

## Импорт базы данных

Вариант через phpMyAdmin:

1. Откройте phpMyAdmin.
2. Создайте новую БД с кодировкой `utf8mb4_unicode_ci`.
3. Импортируйте `database/schema.sql`.
4. Затем импортируйте `database/seed.sql`.

Вариант через консоль:

```bash
mysql -u USER -p < database/schema.sql
mysql -u USER -p < database/seed.sql
```

## Настройка `config/config.php`

Основные поля:

- `app.base_url` — полный URL сайта
- `db.host` — адрес MySQL
- `db.port` — обычно `3306`
- `db.database` — имя БД
- `db.username` — пользователь БД
- `db.password` — пароль БД
- `session.secure` — для HTTPS можно поставить `true`

Если нужен шаблон для копирования, используйте `config/config.example.php`.

## Первый запуск админки

После чистой установки таблица `admins` пустая. В этом случае:

1. Откройте `/admin`
2. Сайт автоматически перенаправит на `/admin/setup`
3. Создайте первого администратора
4. После создания используйте `/admin/login`

Важно:

- страница `/admin/setup` работает только пока в таблице `admins` нет ни одной записи
- пароль хранится в виде `password_hash`

## Как добавить новый тест через админку

1. Войдите в `/admin`
2. Перейдите в раздел `Тесты`
3. Создайте тест
4. Добавьте несколько результатов
5. Добавьте вопросы
6. Для каждого вопроса добавьте ровно 4 ответа
7. У каждого ответа выберите связанный результат
8. Переведите тест в статус `published`

## Как устроена логика результата

- у теста есть заранее созданные результаты
- каждый ответ привязан к одному результату
- при прохождении считается, сколько раз пользователь выбрал ответы, ведущие к каждому результату
- побеждает результат с наибольшим количеством выбранных ответов
- если несколько результатов набрали одинаковое количество, побеждает результат с большим `priority`

## Развертывание на REG.RU

### Вариант 1. Если домен смотрит прямо в папку проекта

1. Загрузите все файлы проекта в корневую папку сайта
2. Импортируйте `database/schema.sql`
3. Импортируйте `database/seed.sql`
4. Настройте `config/config.php`
5. Проверьте права на `uploads/`
6. Откройте домен

### Вариант 2. Если проект лежит в `www/` или `public_html/`

1. Откройте файловый менеджер REG.RU
2. Перейдите в папку домена
3. Загрузите в нее содержимое проекта
4. Убедитесь, что рядом с `index.php` находится `.htaccess`
5. Проверьте, что Apache читает `.htaccess`

## Как указать домен

В файле `config/config.php` укажите:

```php
'base_url' => 'https://domninvyacheslav.online',
```

Если сайт тестируется на временном URL, временно замените значение на адрес тестового домена.

## Права на папки

Папке `uploads/` нужны права на запись.

Обычно достаточно:

- папки: `755`
- файлы: `644`

Если изображения не загружаются:

- проверьте права на `uploads/`, `uploads/tests/`, `uploads/questions/`, `uploads/results/`
- проверьте лимиты PHP на загрузку файлов

## ЧПУ и `.htaccess`

Проект использует `mod_rewrite`.

Проверьте, что:

- Apache поддерживает `.htaccess`
- `mod_rewrite` включен
- файл `.htaccess` загружен вместе с проектом

Если ЧПУ не работают:

1. Убедитесь, что запросы на `/test/...` не дают `404` сервера
2. Проверьте поддержку rewrite-правил в настройках хостинга
3. Если сайт развернут в подпапке, может понадобиться добавить `RewriteBase`

## Частые ошибки и решения

### Ошибка подключения к БД

Проверьте файл `config/config.php`:

- имя базы
- пользователя
- пароль
- хост

### Не открываются красивые URL

- проверьте `.htaccess`
- проверьте `mod_rewrite`
- убедитесь, что сайт открыт через Apache, а не просто как статические файлы

### Не загружаются изображения

- проверьте права на `uploads/`
- проверьте `upload_max_filesize` и `post_max_size`
- проверьте MIME и расширение файла

### Страница результата не открывается напрямую

Это нормальное поведение. Результат доступен только после корректного прохождения теста, потому что маршрут защищен сессионной механикой.

### Не открывается `/admin/setup`

Если администратор уже создан, страница setup отключается автоматически. Используйте `/admin/login`.
